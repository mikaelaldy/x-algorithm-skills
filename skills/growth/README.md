# Growth

Skills for growing an X account using lessons from the public X algorithm.

- **[setup-x-growth-skills](./setup-x-growth-skills/SKILL.md)** — Configure the account brief: audience, pillars, cadence, metrics, and voice rules.
- **[x-growth-strategy](./x-growth-strategy/SKILL.md)** — Create a full X growth strategy from positioning to weekly experiments.
- **[x-content-signals](./x-content-signals/SKILL.md)** — Rewrite posts for dwell, replies, reposts, profile clicks, follows, and low negative feedback.
- **[x-reply-growth](./x-reply-growth/SKILL.md)** — Grow through strategic replies under the right accounts.
- **[x-profile-conversion](./x-profile-conversion/SKILL.md)** — Improve bio, pinned post, header, and profile promise so profile clicks become follows.
- **[x-analytics-loop](./x-analytics-loop/SKILL.md)** — Review weekly metrics and decide what to repeat, stop, or test.
- **[x-content-calendar](./x-content-calendar/SKILL.md)** — Create 7-day or 30-day content calendars using algorithm-signal content pillars.
- **[x-post-audit](./x-post-audit/SKILL.md)** — Audit and improve a draft before publishing.
- **[x-growth-review](./x-growth-review/SKILL.md)** — Audit a full account growth system.
